# A2 AI 独立开发计划

状态：待独立开发与验收。基础为已完成的 1.0.1 release；已有 A2 搜索原型和安全模拟设施可复用，强度尚未评级。A2 不再作为 P4 的补充任务。

## 目标

在冻结卡池中实现可处理任意合法卡组的策略和价值模型，通过信息集搜索及强力卡组联盟自博弈提升水平。结果按卡组、对手及算力报告，正常完成自我对局不等同于能力提升。

不必等待未来扩充包或全部历史卡。先使用当前完整环境，训练与规则版本绑定。新卡先完成规则支持，再扩充训练与重新评测。

## 实施顺序

1. **基线和评测集**：冻结 A1、现有 A2 原型、独立强启发式对手。选择至少六种强力卡组原型，固定完整卡表、种子、先后手和算力。按卡表及原型划分训练、调参、留出集。
2. **公平训练数据**：复用安全分叉、观察采样及 `scripts/cardpool/export_training.py`。记录规则/策略版本、可见观察、合法动作、行为策略概率及结果。不得读取对手手牌、真实牌序、奖赏或服务器随机种子。
3. **策略/价值模型**：以 A1 轨迹初始化，通过卡牌及结构化效果特征学习动作排序和局面价值，保留全决策类型与资源规划场景。
4. **信息集搜索**：采样符合观察的可能世界，用策略引导展开、价值估计收敛；限制模拟次数、耗时和内存，支持取消及 A1 降级，新信息出现后重新规划。
5. **联盟自博弈**：混合当前模型、历史冠军、独立对手及不同卡组，覆盖先后手和镜像局。保留失败、截断和超时。留出评测不参与训练调参。
6. **晋级部署**：离线评测后进行影子运行与受控实战。候选达标才替换冠军，保留权重、特征协议、训练配置、数据范围、版本哈希及回滚点；A1 保持可选。

## 验收门槛（尚非当前成绩）

- 公平性：隐藏状态差分、分叉隔离、卡牌守恒和恢复通过；服务端接受非法动作数为 0，非法提案率低于 0.1%。
- 强度：至少六种原型及独立留出组合，关键对局初始至少 200 局；相同卡组与随机条件换边配对。相对独立强启发式对手的配对得分率 95% 置信区间下界超过 55%。
- 防退化：关键对局不得存在有统计证据的超过五个百分点回退；按原型、先后手、镜像和未见卡表分别报告。
- 成本：调参前冻结硬件、P95 延迟、内存和模拟预算，具体值先实测后确定。超时、降级、截断、异常分别统计，不删除失败样本。
- 真人验证：自动评测通过后安排独立玩家盲测；未经盲测不宣称高水平真人竞技能力。

复用入口：`packages/simulation/a2.py`、`scripts/simulation/evaluate_a2.py`、`data/simulation/evaluation-plan.json`。旧实验数据仅作开发参考，不可重命名为留出成绩。新数据、权重和报告分别建议使用 `data/ai`、`models/ai`、`artifacts/ai`。

闭环：生成对局 → 校验轨迹 → 更新模型 → 冻结候选 → 独立评测 → 晋级或保留冠军。发现规则缺陷时先修复规则、标记受影响数据，再重新评测，防止模型利用错误规则。
