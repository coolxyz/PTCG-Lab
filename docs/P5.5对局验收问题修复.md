# P5.5 完整对局反馈与修复

用户报告完整对局测试已经完成，并提出中文名称、Dark 配色、通信抖动、裁定记录与结束后回放四项问题。Windows 测试环境仍不可用；这次反馈不记作 Windows/WSL2 验收通过。按本次明确反馈开始修复这些显示及功能问题，不再等待整个阶段结束。

## 修复内容

1. **卡牌和招式名称**：同一效果的卡图选择可能命中英文名为空的印刷，覆盖其他印刷的英文别名。资源适配器现在独立合并名称别名、中文技能与中文详情，再选择卡面；界面优先使用 engineId。招式/特性按可见来源卡及同效果技能顺序对应，数量不一致、复制招式或缺少可信中文资料时保留原文，不猜译名称。
2. **配色**：网络页面不再对 `:root`、全局按钮和输入框写入暗色主题。大厅配色与完整产品的浅色主题一致，共享对战边界显式使用 light color-scheme，避免浏览器深色表单控件混入浅色界面。
3. **通信抖动**：后台心跳、房间查询、记录补齐与回放预取不再共用用户操作的 busy 状态；请求仍串行，用户操作等待正在完成的一次后台查询后执行。相同快照不重复覆盖视图，筛选、选牌和弹窗不会因心跳而重置。主动提交时仍保留必要的重复操作保护。
4. **过程和回放**：通过原有 `/frames` 读取成员可见的持久化记录，补齐遗漏步骤；回放自动续页，提供回合时间线，移除原来 300 帧的过小限制（当前加载上限 5000 帧）。终局后正常关闭推送不再误报连接失败。本机持久化快照索引提供历史对局入口，重开浏览器无需手工保存 matchId。
5. **桌面外观与高亮**：针对浅色牌桌高亮不清晰的后续反馈，增加纯色、原创赛事风格桌垫及本地图片导入，默认岩灰；高亮使用深浅双层边框与选中标记。大厅和操作面板保持浅色。用法和存储边界见 [对战桌面外观](P5.5对战桌面外观.md)。

### 裁定记录的准确边界

现有 API v2 存储了可见帧和 visualEffects，但 `events` 列表为空，没有逐动作的完整裁定说明。修复后展示服务器确认的步骤、移动、HP、公开区域数量和终局变化；缺少 effects 的相邻旧帧可按公开数量差异补充。它不推断对手抽到的牌、隐藏选择、技能使用原因或未返回的规则解释。界面明确说明记录来源；未来服务端提供真实事件时优先使用。已存旧对局也可读取，无须重跑或修改历史数据。

## 使用修复包并保留已有对局

包版本：desktop-api `0.5.0.dev8`、online-client `0.5.0.dev4`、desktop-web `0.5.0-p55d`。服务端和裁定规则版本不变。

1. 结束测试操作，用两个终端分别 Ctrl-C 停止本机后台。备份两份旧验收目录，各自保留，不互换游客身份。
2. 解压新包到临时位置，将**新包目录内的文件覆盖到原验收目录**。保留旧 `app/var`、`app/.catalog`、`app/.venv`，不要先删除旧目录。新包不含这三个目录，也不含任何用户状态。
3. 在各自原目录运行以下命令。安装器仅安装新清单中列出的 wheel，忽略覆盖升级后残留的旧 wheel；依赖升级不会重建用户数据库或游客身份。

```sh
python3 manage.py verify
python3 manage.py install
python3 manage.py run --port 18789
# 第二份目录使用 --port 18790 --no-browser
```

4. 使用各自原浏览器配置打开对应本机地址。必要时输入新授权码；不要点击创建新身份来找旧回放。在“继续对局与回放 → 本机对局记录”打开已结束的对局，等“回放已完整加载”后跳至末步。

保留原安装路径可保持 CA 配置与身份目录一致。如果选择全新目录，默认是新安装，不会自动发现旧游客身份；不要把“空历史”误认为旧服务器回放被删除。首次重新安装依赖需要网络或对应平台完整 wheelhouse。
