# P5.5 对战大厅改版

## 布局与交互

大厅采用浅色绿灰配色，连接状态收纳在顶部；桌面并排展示「选择卡组」与「与朋友对战」，窄屏自动变为单栏。下方「我的对局」集中提供继续对战与观看回放入口。

- 卡组：复用平台已保存卡组，展示卡组名称、版本、张数、本地检查提示及实际已提交版本。选中卡组默认选其最新冻结版本，但只有点击「校验并使用此版本」才会替换对战卡组。新冻结版本自动选中，仍需提交。房间内锁定卡组选择。
- 邀请：创建与加入同时可见，房间码自动去空白、转大写，支持 Enter 加入。未提交卡组或服务器暂停接受对局时，两种入口均不可提交。房间内提供复制邀请码、双方准备状态和空位提示，复制失败时保留可手动选择的完整邀请码。
- 对局：全部／进行中／已结束筛选与数量，按完整或部分编号搜索，每页 6 条；显示己方座位、已记录步数、胜利／落败／已结束及对应操作。没有明确胜者时只标记「已结束」，不推断为平局。完整编号可展开查看，通过编号找回入口收纳在列表底部。
- 未确认请求继续沿用原有恢复流程，不重复创建房间或换用新请求。轮询不触发前台忙碌状态，按钮保留位置和键盘焦点。

## 历史记录范围与升级

旧版从最多 8 条可见快照生成记录列表，较早对局会随快照淘汰而消失。本次在同一个受保护的本地凭据文件内增加 `matchHistory` 轻量索引；快照缓存仍保留 8 条，索引不随其淘汰。

索引只包含 `matchId`、`viewerSeat`、`done`、`winner`、`matchSeq`，不包含手牌、凭据、操作权等信息。按首次访问顺序倒序展示，更新已有对局不重复新增。加载旧版凭据文件时从仍保留的快照补齐，后续快照同步时一并持久化。更换服务器隔离，遗忘身份清空。

这是**本机当前服务器、当前身份已访问的对局**，不是跨设备云端战绩列表。旧版已淘汰或其他设备上的对局无法自动列出，可在同一身份下通过对局编号重新访问以补回。状态是最近同步结果；未提供可靠时间、对手名称和历史卡组信息，因此界面不编造这些字段。保留既有凭据文件 8 MiB 容量保护，容量满时报告存储错误，不静默删掉历史。

版本：原生客户端 `0.5.0.dev5`，本地桥接 `0.5.0.dev9`。本次不改变 API v2、共享规则、对战引擎或在线服务器镜像。仅刷新网页可以加载新布局；独立历史索引需要更新本地后台。使用已生成的完整产品包时，需要换用包含新构建的新包。

## 验证

新增浏览器用例覆盖卡组提交与选择区分、最新版本选择、新冻结版本、拒绝提交、创建／加入／离开／准备、复制房间码、轮询稳定性、状态筛选、搜索、分页、回放、空状态、窄屏、通过编号找回、暂停准入与待确认恢复。

新增客户端用例覆盖超过 8 局仍保留索引、快照缓存仍受限、进程重启、旧文件升级、已有记录更新不重复和遗忘身份清空。测试使用隔离数据和模拟网络，未修改正在运行的对战服务或用户凭据。

本次实测：原有浏览器回归 46 项与新增大厅用例 6 项通过；客户端与桌面后台回归 80 项通过、3 项需要独立真实服务的用例未启用。产品双构建、Python lint、迁移／边界／公开源发布门禁通过。视觉检查覆盖桌面双栏、等待房间、390px 窄屏空状态及 Web App 窄内容栏。没有宣称本轮重新执行真实双设备完整对局验收。
