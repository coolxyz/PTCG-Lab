# 同编号多卡面收藏

同一卡号可以包含多个卡面版本，每个版本使用独立的上游 ID 和图片。收藏按卡面记录持有数量，对战仍按卡牌身份计算。

## 使用方法

打开卡牌详情，在“卡面版本与收藏”中查看不同版本的图片。选择品相后，可以分别登记各个版本的持有数量。

- **保存卡面数量**：设置该卡面、该品相的持有数量，同时增减该卡号的收藏总量。
- **分配已有收藏**：将此前登记但未指定卡面的库存分配给该版本，卡号总量保持不变。输入的是该版本分配后的总数量。
- 以前登记的收藏保留为“未分配卡面”，不会自动猜测为普通版；备注、愿望清单保持不变。
- 151 系列已根据上游图片标注普通版、精灵球版、大师球版。其他尚未核实名称的工艺保留工艺编号、稀有度和上游 ID，仍可分别收藏。
