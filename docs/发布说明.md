# 1.0.1 发布说明

2026-10-08，stable。目录按职责重新组织，替代阶段命名；卡牌规则范围保持 G/H/I/J 加八种基本能量，5,346 个目标版本、2,296 种效果全部支持，未支持与待核实例外为零。来源提交与新对战发布 ID 见根 `RELEASE.json`。

## 目录迁移

- 业务包、工具和测试采用 `rules` / `engine`、`collection`、`battle`、`simulation`、`cardpool`、`sync` 等名称。
- Python 虚拟环境为 `.venv`，引擎上游为 `vendor/engine-upstream`，生成引擎为 `runtime/engine`。
- 用户数据库为 `var/app.sqlite`，上传图片为 `var/app-card-images/`。迁移前后用户数据库文件哈希一致，收藏、卡组及对局正文没有改写。
- 数据库环境变量改为 `PTCG_DB`，根启动脚本继续支持 Windows 和 Linux。

目录与模块变动会改变引擎/效果哈希，因此生成新的发布身份，不沿用旧引擎哈希。卡牌、效果的稳定业务 ID 保留。

## 旧版本处理

按用户确认删除旧发布包、历史里程碑归档、研究环境及旧引擎副本。已有对局保存帧可按原身份回放，旧引擎的操作提交被拒绝；未完成对局不能继续。已有卡组重新保存后用于新对局。

Windows 权限拒绝删除的少量旧测试缓存隔离到 `var/cache/locked-*`，不作为应用数据源、不进入 release 或完整备份；它们不是保留的旧运行版本。

## 验证与交付

本次运行完整后端、浏览器回归，并验证迁移后引擎、发布包和旧对局只读回放。准确结果见 `artifacts/release/layout-validation.json`；版本绑定回归证据位于 `artifacts/sync`。Linux 脚本提供 Bash 语法验证，尚无 Linux 实机运行成绩。

`exports/Pokemon-web-1.0.1.tar.gz` 为不含个人数据的安装包，附 SHA-256。解包后运行 `python scripts/release.py verify` 校验，再使用根启动脚本安装及启动。下一阶段为 [A2 AI 独立开发](A2-AI开发计划.md)。
