# P8 原生发布实施记录

2026-10-27：用户授权 P7 运行期间并行开展 P8。2026-10-28 已完成 **P8-A macOS arm64 技术验收**，其余子阶段 planned；P7、P8 总体保持 in_progress，不提前填写容量或跨平台验收结论。

## 本轮范围与隔离

基线 `f3ea9e9`，开发分支 `codex/p8-native-shell`，独立工作树 `var/p8/native-source`。
不修改运行中 P7 驱动／服务镜像，不重启 LAN，不接管其他产品进程或用户目录。
Rust、Cargo 缓存、前端依赖、Python payload 及原生编译输出均在独立目录；Cargo 一次仅运行一个构建任务，降低优先级。
共享宿主机仍存在 IO 和调度竞争，P7 报告保留其实际资源边界和运行条件，不能宣称物理完全隔离。

新增 `packages/platform-services`、`apps/native-shell`、`scripts/native`。
平台能力合同明确 iOS 不含人机与本地规则执行；当前实现仅 macOS arm64，合同不代表 Windows／iOS 适配已完成。

## 已实现的技术路径

- Tauri 壳启动随包 Python，不要求终端执行启动脚本或用户安装 Python／Node／Git。后台绑定随机回环端口，数据写入 preview 身份对应的 Application Support 目录。
- 安装资源与用户数据分离。新入口显式注入数据库路径，卡图覆盖、同步目录、卡组及练习记录随该用户数据库存储；现有浏览器入口继续使用原行为。
- 父子继承管道传输有界 JSON 帧，绑定随机 nonce、PID、端口及协议版本。启动信息不放 URL、命令行或日志。
- 原生壳通过 WebView Cookie API 写入 HttpOnly、SameSite=Strict 的本机会话，再打开同源产品 GUI。HTTP 不提供原生会话创建接口；原有 Host／Origin 校验不放宽，远程页面无原生命令权限。
- macOS 单实例使用私有用户目录内的文件锁及 Unix socket。检查 UID、权限、硬链接和符号链接，通知只接受固定长度 focus 消息并验证对端 UID；不传递 argv、目录或身份凭据。关闭窗口先通知后台退出，超时只终止本壳创建的子进程。
- 启动先检查 payload 文件清单、路径与 SHA-256，拒绝缺失、篡改、额外文件及符号链接。该校验用于完整性检查，正式真实性依赖后续签名／公证，不能由可修改的清单代替。
- 组装脚本只读取明确指定的许可数据／引擎资产；不复制 SQLite、凭据、旧 APP 用户目录或研究输出。冻结规则计算版本所读取的规则集与构建脚本随包保留，运行时不执行构建脚本。

## 固定依赖与开发验证

Rust 1.90.0、Tauri 2.12.5、tauri-build 2.7.4、CLI 2.12.4；直接 Rust 依赖固定版本，完整闭包写入 Cargo.lock。
Python build standalone 3.14.10／20261026 macOS arm64，来源与 SHA-256 写入 `scripts/native/runtime-lock.json`；Python 依赖闭包写入 `python-lock.txt`。
构建目标最低 macOS 12.0；实际兼容性仍需最低系统实机检查。Intel、原生 Windows 和移动端尚未验证。

开发者在 P8 工作树根目录执行，资产路径必须指向已许可的独立资源来源：

```sh
npm ci --ignore-scripts
npm run product:build
python3 -m scripts.native.assemble --runtime var/downloads/python-macos-arm64.tar.gz --assets var/approved-kit/app --output var/native-payload
node node_modules/typescript/bin/tsc -p scripts/native/tsconfig.json
node --test var/native-ts/tests/native/platform.test.js
var/native-payload/python/bin/python3 -B -m pytest tests/native tests/desktop_host/test_host.py tests/desktop_host/test_launch.py
var/native-payload/python/bin/python3 -I -B scripts/native/probe.py var/native-payload
```

Tauri 打包将 payload 根目录映射到 `.app/Contents/Resources/backend/`，配置覆盖文件保存在私有 `var` 下；固定工具链和 `CARGO_BUILD_JOBS=1` 后执行 `npm run tauri --workspace @ptcg/native-shell -- build --debug --bundles app --config <配置文件>`。
产物名称为 **PTCG Lab Preview.app**，使用独立 preview bundle identifier。调试制品不是发行版。

探针从源码目录之外以随包解释器启动，验证两个 GUI 入口、同源会话、人机 session、卡组保存后重开恢复、新本机会话以及安装文件未改变。
Python 原生管道回归覆盖错误消息、跨站会话、并发目录锁、EOF／退出、端口释放和禁止创建授权 HTML；TypeScript 验证桌面／移动能力合同。
本轮已执行：候选随包后台／产品兼容回归 **44 项通过**；包边界／公开导出回归 **150 项通过**（其中原生合同测试有重合，不将数量相加作为独立覆盖率）；Rust 资源清单、进程握手、导航限制和私有单实例 IPC **5 项通过**；平台能力 TypeScript **2 项通过**。
完整产品 GUI 生产构建、全部注册包构建／制品检查、离线安装与公开导出门禁通过。隔离产品探针的 7 个检查全部通过，安装资源无变化。

已生成 macOS arm64 调试 `.app`，复制到源码目录之外后，实际 WebView 成功加载 12807 张卡牌资料、直接进入网络大厅，无终端授权码；通过界面保存长毛巨魔预设并创建 H2 练习，出现独立对战平台与裁定记录。关闭窗口后原生进程、后台子进程及私有通知 socket 均退出／清理。初始启动页的空 URL 路径已修复为显示启动说明。
实际主机为 macOS 27.0.1 arm64。第二次打开使用新的随机端口，仍可看到 1 个卡组和 1 场原有练习，并可继续至原先决策；不是只测试空数据库。截图与执行日志保存在私有 `var`，不进入公开源包；调试 APP 不纳入 Git。仍不把这些技术验证作为自然完整对局或跨平台发布验收。

## 本轮补充验收（2026-10-27）

本轮基于合入 main 的 `43040e7` 在 `codex/p8a-single-rule` 实施；用户已允许更新 LAN。规则兼容清点、部署替换与数据核对见 [单一当前规则决策](单一当前规则与P8A验收.md)。原项目不修改，P7 样本不重标、不重启。

- 原生后台显式选择 macOS Keychain 后端，用系统保存的随机密钥和 AES-GCM 加密整个凭据／待确认请求日志；目录／服务器身份绑定为认证附加数据，每次保存使用新 nonce。系统拒绝访问、密钥缺失、密文损坏或检测到明文时均拒绝继续，不自动重建游客或退回明文。浏览器产品仍按原文件凭据合同运行。
- 增加受控身份导入入口：关闭 APP，按已配置 HTTPS profile 读取旧 vault，保留身份、commandId、游标和原始文件，首次写入目标就是加密状态；目的身份已存在则拒绝覆盖。导入不恢复旧规则。
- 实际 Keychain 验收创建并清理合成测试项，导入后由另一个 Python 进程重新读取同一待确认命令。没有读取或迁移真实用户身份。
- 授权检查覆盖八小时期限、过期窗口撤权及新本机会话；故障检查覆盖父进程 SIGKILL 后管道 EOF 清理、后台 SIGKILL 后端口与 profile 释放、独立 OS 进程的 focus 通知及所有者被杀后的 socket 回收。
- 本轮 Python 原生／授权／客户端及验收门禁回归 **75 项通过，无跳过**（包含实际 Keychain）；Rust **7 项通过**（其中 1 项为子进程辅助入口）；平台 TypeScript **2 项通过**。独立 PostgreSQL 下客户端与桥接 **62 项通过**。边界／公开导出回归 **198 项通过**；全部注册包构建、源码外离线安装及公开导出门禁通过。各批次存在重叠，不相加作为独立覆盖率。
- 重建完整 GUI 和 macOS arm64 调试 APP，最终 payload 含 4570 个清单文件；从源码之外启动的产品探针七项全部通过。Keychain 新增的 cffi／cryptography 原生库实际声明最低 macOS 11.0，Rust 编译目标为 12.0；实际主机仍为 macOS 27.0.1，不能据此宣称最低系统实机验收通过。
- P7 未完成的原测量报告增加不可变快照引用。仅历史模式可接受原 runtime 身份，仍要求当前功能验收和原工具哈希，不授予当前代码容量结论。
