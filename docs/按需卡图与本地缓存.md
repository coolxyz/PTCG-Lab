# 卡图来源：在线缓存与本地克隆目录

App 只提供两种卡图方式，资料库、卡牌详情、卡面版本、人机练习、网络对战和回放共用同一资源接口。卡图不由对战 API v2 传输，也不会授予新规则或卡牌对战资格。

## 在线下载与本机缓存

打开“数据与对战更新 → 卡图来源 → 图片来源与缓存设置”，显示方式选择“在线下载与本机缓存”。在线图源可选 GitHub Raw（默认）或静态图源／CDN。只有实际显示时才下载，核对固定 Git blob、SHA-256、格式、大小与完整解码后缓存；已缓存图片可离线查看。

默认缓存额度 1 GiB，可选 256 MiB、512 MiB、1/2/4/8 GiB。空间不足只淘汰在线缓存，之后显示时重新下载。网络故障只暂停该图，界面最多自动重试 3 次（基础间隔 2、5、15 秒）；429 或带 Retry-After 的 503 按源端指定时间等待。404/410、403、证书或完整性失败不自动重试；多次失败后可以手动重试。

选择 CDN 时填写无凭据、无查询参数的 HTTPS 基础地址。App 追加 `<owner>/<repo>/<固定提交>/<图片路径>`。图源须提供相同原图，不能转码或重定向；自定义域名须解析到公开地址，TLS 和哈希校验不绕过。维护者导出与发布见 [Cloudflare 工具](Cloudflare卡图CDN部署.md)。

## 直接读取本地克隆目录

在已下载完整原图的电脑上，显示方式选择“本地克隆目录”，填写包含 `.git` 和 `img` 的仓库根目录绝对路径（不是 img 子目录）。例如 macOS 的 `/Volumes/<磁盘名称>/PTCG-CHS-Datasets`，Windows 的 `D:\PTCG-CHS-Datasets`。点击“检查本地目录”验证目录和若干示例，再点击“保存设置并刷新卡图”。

- App 不需要安装 Git。不会执行 git、hooks、过滤器或仓库中的任何代码，不自动 fetch、pull、checkout 或修改克隆目录。
- 已验证的缓存可继续使用；缓存未命中时直接从克隆目录读取索引指定的 img 下原图，不复制全库到 App，也不占用在线缓存额度。本地模式不联网补图。
- 不要求 HEAD 等于 App 固定提交；每张实际使用的文件必须与 App／当前同步索引的预期 Git blob 一致，且通过图片大小、类型与完整解码校验。目录版本不同但文件字节相同可以直接使用，字节不同则拒绝，不自动重标身份。
- 缺图、Git LFS 指针未下载、目录移动／磁盘未连接、访问权限不足、字节不匹配会明确提示。修复原图或目录路径后手动重试；不修改规则或卡表。
- 只读取指定目录，不向浏览器暴露任意文件服务；拒绝目录穿越、符号链接、Windows 目录联接、网络共享路径及非普通图片文件。设置保存在这台电脑的 profile 内，跨设备迁移后须重新指定当地路径。

ZIP 展示资源导入、激活和单张上传功能已移除，相应 API 和制作工具不再提供，也不加载旧展示包覆盖。已有文件、收藏、卡组、凭据和历史记录不会因此自动删除。软件安装 ZIP、备份及通用的已验证历史资源缓存不属于卡图 ZIP 导入功能。

## 固定图片索引

当前随包索引位于 `resources/artwork/builtin-index.json`，固定上游提交 `3f9648f364caa750a18b56bb8e9d562c4c17689f`，精确匹配 12,931 条；26 条牌面歧义不自动选图。随包另带 `resources/artwork/builtin-snapshot.json`，包含全部 20,713 个明确卡面 ID 的路径和 blob，不含图片。新安装且未同步资料时，也可直接读取本地的其他稀有度卡面。优先级为当前同步索引 → 精确印刷索引 → 随包卡面索引；未匹配才显示占位，不直接请求未经索引校验的浏览器远程地址。

开发者可在固定 Git 对象缓存上生成新索引：

```sh
python -B scripts/product/build_image_index.py \
  --catalog <批准资产目录>/data/catalog/catalog.json \
  --cache <专用Git缓存目录> \
  --commit <完整固定提交> \
  --output <新的索引JSON路径>
```

生成全卡面元数据时对上述命令增加 `--snapshot` 并选择新的输出文件；维护者核对后更新随包 `builtin-snapshot.json`，两份索引必须绑定同一批准卡表。维护端 Git 工具与 App 的直接文件读取是两条独立路径。App 不需要运行维护工具；来源设置不会更新卡牌规则。

## 验证与备份

定向验证覆盖本地读取不执行命令／不联网／不复制全库、目录与哈希拒绝、重开、两种来源切换、旧覆盖不再生效、原文件保留，以及在线缓存和有限重试。实际交付记录在 release 批次的 VALIDATION.json；Windows 交叉编译不等于实机验收。

备份前关闭目标后台，保存完整 profile／同步目录和需要离线保留的缓存；外部克隆仓库单独备份或重新 clone。仅有 profile 内的路径设置不能恢复外部原图。迁移与受控升级见 [使用手册](启动使用与跨系统迁移.md)。
