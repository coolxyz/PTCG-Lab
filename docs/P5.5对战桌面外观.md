# P5.5 对战桌面外观

## 使用方式

在人机练习、网络对战或回放界面，点击右上角 **桌面外观**。选择后可以在弹窗内预览，再点击 **保存外观**；取消或按 Escape 不修改当前桌面。全屏状态下也能打开设置。

- 纯色：岩灰（默认）、墨绿、深蓝、暗紫、暖沙。
- 赛事风格桌垫：经典赛场、红蓝对阵、蓝色竞技场。三张图案为项目原创 SVG，随源码与构建包发布，不是官方赛事图片。
- 自己的桌垫：导入已有 PTCG 桌垫或其他 JPG、PNG、WebP 图片，单张不超过 5 MB、3200 万像素。图片自动缩放至不超过 1600 × 1200、重新编码为 JPEG；显示时居中裁切铺满，并增加暗色遮罩保证文字可读。可移除图片，或恢复默认外观。

设置和图片仅保存在**当前浏览器、当前本机 APP 地址**中。同一地址内的人机练习、网络对战和回放共用；不同浏览器、设备或端口各自保存，不会同步给对手。清理网站数据会清除偏好。浏览器禁止存储或容量不足时，外观仍会应用到当前窗口，并显示无法持久保存的提示。

## 显示与实现

桌面配色独立于大厅、操作面板和裁定记录的浅色主题。可操作牌使用青色与深色双层边框，已选牌使用橙棕色与白色边框并显示勾选标记；键盘焦点使用虚线外框，拖放目标使用虚线提示。效果结算仍有位移动画，但降低原有亮度闪烁，避免卡面被冲白。

共享 `battle-ui` 负责设置弹窗、预览、图片解码和样式，通过 `appearanceStorage` 端口交给 `desktop-web` 保存。唯一新增的存储适配器为 `apps/desktop-web/src/appearance-storage.ts`，只保存版本化的外观配置，不读取身份或对局状态。包边界检查仅允许该宿主文件使用浏览器偏好存储；显示包继续禁止网络和存储能力。

内置桌垫打包到前端，本地导入图像以受限的 raster data URL 保存，不接受远程图片地址、SVG 或 HTML。沿用现有 CSP 的 `img-src 'self' data:`，没有新增 API、运行依赖或图片服务器流量。外观变更不重挂载控制器，不提交对战命令，也不清空选牌或回放位置。

## 验证与交付

共享 GUI 浏览器回归共 13 项，包含所有内置配色、浅色背景选牌高亮、取消与焦点恢复、刷新后保存、回放复用、全屏、390px 窄屏、图片缩放与移除、无效/超限图片、存储失败降级，以及原有双座位与回放回归。构建和迁移发布门禁检查同时执行。

更新包继续按 [对局验收问题修复](P5.5对局验收问题修复.md) 中的覆盖升级步骤使用，保留旧 `app/var`、`app/.catalog` 和 `app/.venv`。该功能不需要升级或重启 API v2 服务。
