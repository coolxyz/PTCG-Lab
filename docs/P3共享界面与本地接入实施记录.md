## 2. P3-A 交付时的边界（后续变更见 P3-B 记录）

`@ptcg/battle-ui`（`0.3.0-p3a`）导出 BattleArena、BattleScreen、展示 DTO 和 playerLabel。选择性移植研究环境的牌桌、检索浏览、卡牌说明、事件/投币显示与样式；未移植图片上传、网络房间客户端、Battle 人机控制器或 AI 代码。读取来源的哈希保留在本地 `var/p3/research-ui-inputs.json`，不加载研究环境的依赖或运行时。

- 共享界面只接收已授权的 BattleView、宿主提供的显示目录和回调，发出 optionId/selectedRefs 选择意图；不生成规则结果、命令 ID 或重试请求。
- 卡图 URL 来自宿主传入的 CardInfo，不在组件中查询目录或下载资源包；未提供卡图和图片加载失败时，卡名、HP、动作与文字仍可使用。卡图的浏览器正常加载与模式 API 请求分属不同边界。
- 组件内定时器仅用于动画展示。回放计时、网络重试、AI 推进、认证和会话由模式适配器管理。CSS 只隐藏页面滚动，不依赖宿主必须名为 `#root`；宿主负责隐藏导航并保持控制器挂载。
- 视角由 viewerSeat 指定，决策权限按 decision.actor；非回合方仍可操作自己的决策。回放禁用操作，网络演示不传入 AI 控件。
- 明示奖赏候选显示公开名称与位置，背面候选只显示序号。检索浏览和同版本刷新不清除已选引用；新局、新状态、决策 ID、视角或回放模式变化会重置选择。
- 系统全屏可进入/退出，退出界面时清理全屏和滚动锁；不支持或被拒绝时保留完整窗口并给出提示。裁定记录只有内部列表按需滚动。

`@ptcg/desktop-web`（`0.3.0-p3a`）实现纯展示适配 `snapshotView` / `replayView`，接收已经通过 v2 校验及成员授权的 DTO，复制成独立的显示对象。它不是网络输入验证器，不替代未来 P5 的认证/资源边界。保留局面、合法引用、公开效果、结果、明示奖赏和只读回放；无事件日志的 visualEffects 也单独展示，不生成虚构裁定记录。HP 的数字字符串转换为显示数字，空或非数字值不显示数值 HP。

合成 DemoApp 由宿主管理显示/离开、回放进度及选择回调，明确显示“尚未连接服务器”。按钮只回传演示选择，不推进真实规则、不创建房间或伪造在线成员。页面来回切换保留宿主快照；不会新建对局或产生 AI 循环。

本次 npm workspaces 只扩展既有骨架工作区；旧 `apps/web` 未搬移、未加入工作区。新包当前是供 Vite/TypeScript 构建器消费的源码导出，不能当作无需编译的 Node.js 运行包或已发布稳定 SDK。React/ReactDOM 使用同一固定版本与单实例解析。

## 4. 复现

在仓库根目录：

```sh
npm ci --ignore-scripts
npm run p3:build
npx playwright install chromium
npm run p3:test
npm run p3:dev
```

演示默认只监听 `http://127.0.0.1:5183`，严格拒绝占用的端口，不代理 `/api`。运行演示不需要卡牌资源、后端数据库或 AI。保持现有服务运行，不启动旧 8765/8770/8443 入口。浏览器测试默认启动并关闭自己的演示服务，不能同时复用手动启动的同端口服务。已有 Chrome 可通过 `PTCG_BROWSER_PATH` 指定测试可执行文件。

独立包检查沿用发布门禁生成 tgz，再运行：

```sh
python scripts/migration/gate.py --build-output var/p3/new-build \
  --dependency-wheelhouse var/p2/wheelhouse
node scripts/migration/p3_package_smoke.mjs var/p3/new-build
```

## 5. 接入清单（1—4 由 P3-B 落实，5—6 已由 P3-C 验收）

1. 从 PTCG-Lab 冻结产品的 Battle 控制器提取本地模式适配器，先比较其当前 API/会话/回放接口；不整份覆盖研究环境最新 Battle 或 AI 文件。
2. 控制器持续挂载并唯一持有命令、重试、会话、AI 推进及动画等待。进入/退出显示和系统全屏不触发 start/reset/第二个 AI 循环；视图不保存认证。
3. 保留原 H2 默认、五套匹配策略和 AI 接口。接入前固定接口/交互基线；先接已有旧运行链，避免本阶段同时迁移历史对局规则身份。
4. 对本地 live/replay 数据分别映射；旧回放显示其原记录，不从当前局面重算。网络模式继续保持合成未连接状态，真实连接交给 P4/P5。
5. 在隔离数据库验证收藏、构筑、资料同步、开局、刷新恢复、认输、回放、速度/暂停/单步/动画等待以及导航往返；然后才决定是否切换兼容启动入口。
6. 保存旧构建并验证渲染回滚，不迁移/改写研究数据库、在线局、历史摘要和模型。P3 完成标记依赖以上验收，不以本页合成演示代替。
