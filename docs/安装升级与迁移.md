# 安装升级与迁移

升级前关闭 App，备份整个用户 profile。macOS 默认位于 `~/Library/Application Support/org.ptcglab.desktop.preview`，Windows 位于 `%LOCALAPPDATA%\org.ptcglab.desktop.preview`。不要用删除安装标记、数据库或凭据的方式绕过保护提示。

## macOS 受控安装

推荐使用正式构建的 DMG 中的 `Install PTCG Lab.command`。安装器校验完整 App 的可信 bundle 摘要，将应用和 profile 作为配套事务备份与切换。首次采用已有资料必须显式确认 adopt；运行中的资料目录会拒绝安装。

维护者也可运行：

```sh
python3 scripts/product/desktop_install.py --root /path/to/install-root --state-dir /path/to/profile status
python3 scripts/product/desktop_install.py --root /path/to/install-root --state-dir /path/to/profile install --candidate '/path/to/PTCG Lab Preview.app' --sha256 TRUSTED_BUNDLE_SHA256
```

`TRUSTED_BUNDLE_SHA256` 是安装工具的 App bundle 摘要，不能用 ZIP 文件摘要替代。已有资料首次采用时增加 `--adopt`。事务中断后先检查 status，再用 `recover --mode finish` 或 `recover --mode abort`；不要手动混合候选文件。回退为 `rollback --transaction TRANSACTION_ID --expected CURRENT_BUNDLE_SHA256`，恢复整套应用和配套状态，不按单局切换旧规则。

## Windows

便携 ZIP 完整解压后运行 `Verify.ps1`，再打开 EXE。原生 Windows 安装、升级和回退仍需实机验证，发布状态继续 pending。不要覆盖正在运行的目录；保持 EXE 与 backend 的相对位置。维护者的原生构建验证入口见 [构建与发布](构建与发布.md)，人工步骤见 [Windows 验证](Windows验证步骤.md)。

## 网络身份交接

配置服务器与创建/导入身份是分开的动作。关闭 App，用 Mac `scripts/packaging/configure_macos.py` 或 Windows `configure-server.cmd --client-kit PATH` 安装公开连接信息，不复制任何身份。具体 Mac 参数见使用手册。

已有在线身份使用 `ptcg_desktop_api.identity` 的加密 export/import 流程，Windows 可用随包 `identity.cmd`。先查看 `--help`，口令仅在终端隐藏输入，目标必须是新的受保护身份目录。先停止原客户端并备份，不能同时在两台设备继续使用相同身份控制对局。不能直接跨设备复制 Keychain/DPAPI 密文。

身份交接保留服务器身份、未确认命令与恢复记录，仍核对当前规则，不迁移或重标旧规则。卡组可使用界面导出/导入，在线图片缓存和离线展示资源独立管理，详见 [使用手册](启动使用与跨系统迁移.md)。
