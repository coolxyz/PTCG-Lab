# 检索期间浏览完整牌库

真正检索整副牌库时，选牌面板提供“浏览我方完整牌库 · N 张”。展开后可按中文名、英文名、卡号搜索，按宝可梦、训练家、能量筛选；相同卡牌合并显示数量，展开单卡可查看图片及效果说明。

浏览区只供查看。选择要拿取的牌仍在原来的候选区完成；搜索、筛选、展开详情或收起不会取消已选卡牌，也不会自动提交。确认按钮只提交合法候选的引用。进入下一项决策后，浏览筛选重置。

牌库清单不表示真实顺序，也不额外展示奖赏卡。多阶段检索展示当前阶段剩余的牌库。权限由规则明确授予，不能根据候选位于牌库就推断：查看顶 N 张、弃牌区回收、支付手牌费用不授予完整浏览权限。没有匹配卡时仍可查看并提交空选择继续。合法的对方牌库检索也只向行动方开放。

历史对局列表同时修正了对手名称：预设显示实际名称，自定义卡组显示名称和版本；原版本已删除或旧预设已移除时，使用明确的历史提示。

## AI 可见信息

`decision.deckInspection` 包含牌库所有者、总数、无序声明及按卡牌合并的数量，不携带真实牌库索引或可提交引用。H2 和五专家通过相同的 Adapter / runtime.view 获得合法观察。

本次同步保留 PTCG-Lab 的长毛巨魔 v1、沙奈朵 v5、多龙 v1、N 索罗亚克 v2、电电虫 v1，只更新其环境指纹及默认策略包指纹，不修改策略权重或引入新的策略版本。现有策略尚未利用新字段实现跨回合记忆或卡奖推断；获得信息不代表棋力提升。

## 更新与版本

规则、生成引擎和效果清单必须配套。已有安装先备份，再准备匹配的本地资产，按 [H2 使用与升级](H2使用与升级.md) 发布新的 API 快照。只更新前端或刷新浏览器无法升级已冻结的后台。旧发布和旧对局保持原版本，新开对局才能使用新增权限。

源码包含显式检索权限、固定上游检索调用的构建补丁和界面；完整引擎、卡池、效果清单仍是需另行准备的本地资产，不随公开 Git 仓库提交。不能通过忽略完整性校验或单独修改环境哈希来混用旧资产。
