# 移动依赖许可补充

补充锁定 crate 没有随附的上游声明和标准许可原文。每项绑定精确版本、crate SHA-256、.cargo_vcs_info 中的提交与工作区路径；每份文本另核对 SHA-256。构建时全离线，不修改原 crate 或 Cargo.lock。

objc2 家族保留原 LICENSE.md（包括其 Apple SDK 说明），另附标准 MIT 条款；标准条款不是把本项目版权替换为上游版权。原始作者与上游地址从该版 crate 元数据保留。selectors 附标准 MPL-2.0 和精确未修改源代码下载地址，生成的署名文件说明如何取得源码。zune-core 使用该版上游的 Zlib 原文。

这些材料解决许可内容/来源证据缺口，不替代对 Apple SDK、卡牌文字、图片或商标分发权的审阅；公开源码的 MIT 不覆盖这些第三方资产。
