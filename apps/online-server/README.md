# 纯 API v2 对战服务

负责房间码邀请、成员授权、权威命令、版本化提交、私有事件与回放；PostgreSQL 为持久化真相，worker 有界执行当前批准规则。没有 GUI 或卡图分发。配置见 ops/online。

产品边界见 [架构与维护](../../docs/架构与维护.md)，使用与部署见 [使用手册](../../docs/启动使用与跨系统迁移.md) 和 [构建与发布](../../docs/构建与发布.md)。包版本以本目录元数据为准。

公网交付使用 [Caddy 自动证书网关及数据库备份恢复](../../docs/API公网部署与自动证书.md)，API 与 PostgreSQL 均不直接发布端口。当前 worker 默认 RSS 回收阈值为 384 MiB，避免当前卡表正常恢复约 279 MiB 时反复冷启动；这是单 worker 预算，不代表容器总内存或正式并发容量。
